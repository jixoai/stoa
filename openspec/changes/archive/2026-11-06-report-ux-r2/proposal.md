# Proposal: report-ux-r2

## 背景（Owner 2026-11-06 二轮走查）

1. 移动端首页顶部还写着「主页」，而下面已经是 tabs；桌面右侧那栏（连接信息＋成员列表）在移动端没有入口。
2. 底部 tab 切换会 push 历史，导致返回键要按很多次。
3. 根页继续返回时直接关页面，没有提醒。
4. 静态资源缓存策略错误（`app.js` 无内容哈希却 immutable 一年）——已由协调者修复（hash 文件名）。
5. 标签是裸露的选择器，不符合 X 直觉；应该**在正文里输入 `#` 触发补全**，发送时从正文提取、显示时高亮。
6. 搜索页没有热门标签（X 有趋势）。
7. 搜索页没有推荐成员（X 有推荐关注）。

## 变更

1. **移动端 header**：首页不显示页面标题（tabs 即标题）；右侧加一个 **sheet 入口**，展开桌面右栏的内容（连接信息 ＋ 成员列表）。
2. **tab 切换用 replace**：不产生历史条目；只有进入子页才 push。
3. **关闭提醒**：根页再返回触发确认（`CloseWatcher` 优先，降级为合成历史条目＋拦截）。
4. **标签即正文**：输入 `#` 触发补全面板（热门标签＋自由输入），发送时用正则从正文抽取 `#tag` 写入 `tags`，渲染时高亮；移除独立的标签选择器。
5. **发现接口**：`GET /api/tags/trending`（按数量＋近期活跃打分）与 `GET /api/accounts/suggested`（粉丝数＋近期活跃，排除自己）。
6. **搜索页**：空查询时展示「热门标签」与「推荐成员」；有查询时展示帖子与成员结果。

## 非目标

- 不做全文索引/复杂检索语法。
- 不做个性化推荐模型（打分规则透明、可解释）。
